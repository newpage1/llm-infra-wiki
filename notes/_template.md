> 文件名就是网址里的 slug，用英文小写加连字符，例如 `kv-index-comparison.md`。

## 正文从二级标题开始

上面 `---` 之间那段叫 front-matter，四个字段都是**必填**：

| 字段 | 说明 |
|---|---|
| `title` | 标题 |
| `author` | 你的名字 |
| `date` | `YYYY-MM-DD`，必须这个格式 |
| `summary` | 一句话摘要，列表页显示 |
| `tags` | 选填，写成 `[标签1, 标签2]` |

## 能用的写法

普通 markdown 都能用。几个约定：

- 行内代码用 `%%双百分号%%` 包起来（不是反引号），例如 `%%BlockPool%%`——这是本站的惯例，
  渲染出来是等宽小字。**注意 `%%` 里不能再出现 `%` 字符**。
- 代码块要写语言标记：`~~~python` 或 ` ```python `。
- 表格、引用、有序无序列表、外链都正常。

```python
# 代码块会被逐字保留
def example():
    return 1
```

## 图

把 SVG 文件**和 md 放在同一个目录**，正文里用图片语法引用：

```markdown
![这张图画了什么](你的文件名.svg)
```

几个要点：

- SVG 会被**内联**进页面（不是当图片加载），所以站点的图能直接拿来用——
  `fill="var(--panel)"`、`class="t-mono"` 这些主题变量和样式都生效。
  想省事就复制一张 `diagrams/*.svg` 改。
- `xmlns="http://www.w3.org/2000/svg"` 建议带上（内联后不影响，但文件单独打开要靠它）。
- 位图（`.png` / `.jpg`）也支持，用 `<img>` 加载。
- **别用外部图床**——本站不依赖任何外部资源，图必须跟着仓库走。
- 一张图只画一件事。宽高比控制在 3:1 以内，横着铺满屏幕比竖着长好看。

## 引用代码位置

写 `路径:行号`（例如 `python/sglang/srt/mem_cache/radix_cache.py:88`）时，
请**真的去那一行看过**。这类锚点会被 `tools/check_notes.js` 抽查，
行号对不上会在 PR 检查里报出来。

## 写完之后

1. `node tools/build_notes.js --lint` —— 两秒，查 front-matter 与图片、锚点
2. `bash tools/verify.sh` —— 全套（含站内链接）
3. 提 PR

清单（`notes/manifest.json`）**不用你管**：合进 main 后由 CI 重建并提交。
